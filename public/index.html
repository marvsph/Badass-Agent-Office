A REAL WINDOW INTO YOUR WORK

Welcome to Agent Office.

Each worker represents a local Codex, Claude Code, or Copilot CLI session. Their project determines their floor. VS Code and other IDE workflows appear when their agents write these supported local records. Configure your project folder paths to give them floors. An open IDE window alone does not indicate work.

Rooms and worker activities are animated decoration. The observed status is shown separately. A recorded wait for subagents sends the worker to the team lounge; finished turns trigger cafeteria and game-room breaks. A quiet log means unknown, not active.

The observer reads local records without changing them. Create task starts a separate local Codex or Claude Code task only when you press Send. Tasks started here accept follow-up messages after a turn finishes. Existing conversations started in other apps remain controlled there.

Workers leave the floor after six hours without recorded activity and return when their session has a new record. Earlier records shows older sessions in the people list without adding workers to the canvas. Providers without readable local records, remote machines, and unsupported chat windows do not appear automatically.

Office display stays local · Tasks use the selected provider's local login
